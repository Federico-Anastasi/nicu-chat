# Name and logo

The code is open source. The name "Nicu", the Nicu character's artwork used as logo (the icons and the face on
nicu.chat) and the nicu.chat name are not covered by the code's license and remain with Federico Anastasi, so that
people can tell the original project from other versions.

**You can, without asking:**
- use the name to refer to the project, for example in an article, a tutorial or a comparison;
- say that your work is "based on Nicu", or "works with Nicu", if that is true;
- keep the name and logo in unmodified copies of the official releases.

**You need permission to:**
- use the name or logo for a modified version, a fork, a product or a service: give it a different name and logo;
- use them in a way that suggests the original project made or endorses your work;
- use them in a company name, a product name or a domain name.

To ask for permission, open an issue in this repository.
